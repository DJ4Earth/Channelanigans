Container image and raw data behind the CPU automatic-differentiation (AD) cost table of the Channelanigans artifact, measured with current package versions (Julia 1.12.7, Reactant 0.2.304, Enzyme 0.13.216, Oceananigans 0.116.1, Checkpointing.jl 0.13.0).

The benchmark measures the cost of one reverse-mode gradient of an Oceananigans reentrant-channel ocean model (80×160×32 immersed-boundary grid, Float64, zonal transport objective) over N = 4, 8, 16, 32, 64, 128 and 256 time steps, for 9 AD configurations: Reactant/Enzyme-MLIR compiled through XLA with different optimization, min-cut and checkpointing options, and Enzyme (LLVM) without Reactant, with and without binomial checkpointing. Each case ran on one TACC Vista Grace-Grace (gg) node, pinned to one core: 1 warmup call, then 12 measured calls, each on a freshly built problem. Reported: wall-clock time per call, peak resident memory (VmHWM), and hardware-counted floating-point operations (Neoverse V2 events r80C0 + r80C1). 60 of 63 cases finished; 3 ran out of the node's 237 GiB.

The table, per-case JSON records, CSV exports and full documentation are in the GitHub repository, data/vista_2026-11/ (README.md there). This record holds what is too large for git, plus the software environment needed to rerun.

Reading the data. The ± values in the table are 95% Student-t confidence intervals over the 12 calls on one node. Runtimes also vary between Vista nodes, by about 6% to 20% for the same run in memory-heavy cases, and cases ran on whichever node was free; this spread is not in the intervals. Memory and FLOP counts agree across nodes to within 0.5%. All configurations agree with the reference configuration in objective and full gradient fields to within 1.9e-12 (relative).

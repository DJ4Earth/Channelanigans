Container image and raw data behind the CPU automatic-differentiation (AD) cost table of the Channelanigans artifact, rerun in November 2026 with the package versions of the original July/August 2026 runs (Julia 1.11.9 and the August 3, 2026 Manifest: Reactant 0.2.279, Enzyme 0.13.198, Oceananigans 0.110.14, Checkpointing.jl 0.12.0). The record also contains the original July/August 2026 runs and the scripts that produced them.

The benchmark measures the cost of one reverse-mode gradient of an Oceananigans reentrant-channel ocean model (80×160×32 immersed-boundary grid, Float64, zonal transport objective) over N = 4, 8, 16, 32, 64, 128 and 256 time steps, for the 8 AD configurations of the original table: Reactant/Enzyme-MLIR compiled through XLA with different optimization, min-cut and checkpointing options, and Enzyme (LLVM) without Reactant. Each case ran on one TACC Vista Grace-Grace (gg) node, pinned to one core, with the runtime flags of the original job scripts (Julia -O2, multi-output fusion, XLA's multi-threaded Eigen at its default): 1 warmup call, then 12 measured calls, each on a freshly built problem. Reported: wall-clock time per call, peak resident memory (VmHWM), and hardware-counted floating-point operations (Neoverse V2 events r80C0 + r80C1). 53 of 56 cases finished; 3 ran out of the node's 237 GiB.

The table, per-case JSON records, CSV exports and full documentation, including how this rerun differs from the original runs, are in the GitHub repository, data/vista_2026-11_aug2026/ (README.md there). This record holds what is too large for git, the software environment, the diagnostic jobs the README cites, and the original runs.

Reading the data. The ± values in the table are 95% Student-t confidence intervals over the 12 calls on one node. Runtimes also vary between Vista nodes, by about 6% to 20% for the same run in memory-heavy cases, and cases ran on whichever node was free; this spread is not in the intervals, and it is the main reason runtimes differ from the original runs. Memory and FLOP counts agree across nodes to within 0.5%. Unlike the current-version record, not every configuration reproduces the reference gradient to 1e-10: reactant_after_enzyme at N ≥ 32 and reactant_binomial_10 at N = 8 differ by up to about 5e-4 (open issue), and three configurations by up to 2e-7. Details in the data README.
